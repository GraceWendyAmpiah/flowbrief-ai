# FlowBrief AI

**Banking Workflow Intelligence Assistant**

A lightweight document intelligence and workflow routing
assistant that helps internal banking staff classify
customer requests, extract structured information,
identify missing documents, and generate staff handoff
reports.

Built as a technical demonstration for a
Société Générale Ghana IT Developer application.

---

## Tech Stack

- AI layer: Groq API — llama-3.1-8b-instant + llama-3.3-70b-versatile
  (OpenAI-compatible SDK, open-source Llama models)

Full documentation in progress.
